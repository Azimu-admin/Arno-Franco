# Site web – Arno Franco, Naturellement Professionnel

Site vitrine d'Arno Franco, aménagement et entretien de jardins à Theux / La Reid (province de Liège).

- `public/` – **le site publié** (seul dossier servi par Vercel) : `index.html`, pages légales, `404.html`, `robots.txt`, `sitemap.xml`, `img/`
- `logo-source/` – logo d'origine (PDF Illustrator) et version SVG
- `PROJET.md` – fiche projet : infos de l'entreprise, couleurs, éléments à confirmer, ce qu'il reste à obtenir d'Arno

- `LANCEMENT.md` – procédure de lancement (réactiver l'indexation, domaine)

Pour voir le site en local : `python3 -m http.server -d public 8000`, puis ouvrir http://localhost:8000.
