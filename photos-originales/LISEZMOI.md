# Photos originales (internes, jamais publiées telles quelles)

Ce dossier est hors de `public/` : Vercel ne le publie pas (voir vercel.json → outputDirectory et .vercelignore).
Claude y prend les originaux, les trie, les optimise (taille, WebP, suppression des données GPS/EXIF)
et place uniquement les versions web dans `public/img/realisations/`.

## Rangement conseillé (un sous-dossier par thème)
creation/  entretien/  elagage/  abattage/  terrassement/  terrasses-allees/
pierre-naturelle/  clotures/  piscine/  avant-apres/  arno/  divers/

## Informations utiles (dans `infos.txt`, une ligne par photo ou par chantier)
nom-du-fichier ; commune ; type de travaux ; avant/après ; accord du client pour publier (oui/non)

## Attention
- Vérifier l'accord des clients : maison reconnaissable, numéro, plaque d'immatriculation, personnes.
- Les photos de téléphone contiennent souvent la position GPS du chantier : elle sera retirée des versions web.
